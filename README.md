# OBS HSL Filter

**用于 OBS Studio 的实时八色 HSL 调色滤镜。**

Real-time 8-color HSL color grading filter for OBS Studio.

在 OBS 内直接调整画面的色相、饱和度和明度。支持全局调整与八种颜色独立调整，适合直播画面校色、肤色微调、产品颜色调整及多机位色彩匹配。

插件作为 OBS 原生视频效果滤镜运行，无需额外打开独立调色软件。

## 功能

- **全局 HSL 调整**：统一控制整幅画面的色相、饱和度和明度。
- **八色独立调整**：分别调整红、橙、黄、绿、青、蓝、紫、洋红。
- **平滑色相过渡**：使用柔和的颜色范围遮罩，减少相邻颜色之间的突变。
- **低饱和度区域保护**：降低调整对白色、灰色和黑色区域的意外染色。
- **GPU 实时处理**：适用于摄像头、采集卡和媒体源等实时视频画面。
- **多实例独立参数**：不同来源上的滤镜可以分别设置。
- **参数自动保存**：调色参数随 OBS 配置保存。
- 支持旁路、重置及中文 / 英文界面。

## 八色 HSL 调整

| 颜色区域 | Hue 色相 | Saturation 饱和度 | Lightness 明度 |
| --- | --- | --- | --- |
| 红色 Red | ✓ | ✓ | ✓ |
| 橙色 Orange | ✓ | ✓ | ✓ |
| 黄色 Yellow | ✓ | ✓ | ✓ |
| 绿色 Green | ✓ | ✓ | ✓ |
| 青色 Cyan | ✓ | ✓ | ✓ |
| 蓝色 Blue | ✓ | ✓ | ✓ |
| 紫色 Purple | ✓ | ✓ | ✓ |
| 洋红 Magenta | ✓ | ✓ | ✓ |

颜色区域按画面中的颜色选取，不按物体选取。例如，调整橙色时，肤色和画面中的其他橙色物体都可能受到影响。

## 下载与安装

1. 打开本仓库的 **Releases** 页面。
2. 下载适用于 Windows 的安装包。
3. 正常退出 OBS Studio。
4. 运行安装程序，按提示完成安装。
5. 重新打开 OBS Studio。

## 使用方法

1. 在 OBS 的“来源”列表中，右键点击需要调色的摄像头、采集卡或媒体源。
2. 打开“滤镜”。
3. 在“效果滤镜”区域点击 **＋**，添加本插件提供的 HSL 滤镜。
4. 使用全局 HSL 调整整体画面，再按需要微调各个颜色区域。
5. 使用旁路功能对比调整前后的效果。

不同来源可以使用不同参数。关闭并重新打开 OBS 后，已保存的滤镜参数会自动恢复。

## 调整建议

- **肤色微调**：从橙色和红色开始，小幅调整并观察脸部、嘴唇及背景颜色。
- **产品颜色调整**：选择产品对应的颜色区域，结合实物参考检查效果。
- **多机位匹配**：先匹配各相机的曝光与白平衡，再使用 HSL 微调颜色差异。
- **特定颜色增强**：适当增加目标颜色的饱和度，同时检查相邻颜色的过渡。

建议先保证光线、曝光和白平衡基本正确，再进行 HSL 调整。较大的色相或饱和度变化可能产生不自然的颜色。

## 处理方式

插件使用 GPU Shader 进行实时图像处理，通过平滑的色相范围遮罩混合各颜色区域的调整结果，并处理色相首尾相接的循环关系。

低饱和度区域保护用于减少中性色受到的影响，但不代表这些区域在所有参数下都完全不变。

本插件主要面向直播和实时视频调色，不提供物体识别或自动肤色跟踪。
